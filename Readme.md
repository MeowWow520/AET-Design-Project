# Analog Electronic Technology Design Project

## 课题: 水温控制系统设计

## 系统框图

```
温度传感器 → 信号调理电路 → 比较/控制电路 → 驱动执行(加热/制冷)
                   ↓
               参考电压(设定温度)
```

## 设计步骤

| 阶段 | 内容 | 要点 |
|------|------|------|
| **1. 需求分析** | 确定控温范围、精度、响应时间、显示方式 | 典型：室温~100°C，±1°C |
| **2. 传感器选型** | NTC 热敏电阻 或 LM35 + 电桥电路 | 纯模拟方案，符合课设要求 |
| **3. 信号调理** | 差分放大/仪表放大（运放如 LM324/LM358）→ 将微弱信号放大到合适范围 | 计算放大倍数 |
| **4. 比较控制** | 运放构成的比较器，与可调参考电压（电位器分压）比较 → 输出开/关信号 | 可引入迟滞比较器避免震荡 |
| **5. 驱动执行** | 比较器输出 → 三极管/MOSFET/继电器 → 加热丝（如电热棒） | 注意功率匹配和隔离 |
| **6. 辅助电路** | 电源（如 7805/7812）、指示灯（加热/停止）、可选的数码管显示 | |
| **7. 仿真验证** | 用 Multisim / Proteus 搭建仿真验证 | 课设通常要求仿真截图 |
| **8. PCB 设计** | Altium Designer / 立创EDA 布局布线 | 视要求而定 |

## 设计要求

本设计应着重**模拟电子电路**设计，严格符合本科《模拟电子技术》课程的毕业要求。优先采用运放、三极管、电阻电容等分立/集成模拟器件完成温度传感、信号调理、比较控制与驱动执行。**单片机等数字/嵌入式方案仅作为辅助或次次要手段**，不得替代核心模电模块。
