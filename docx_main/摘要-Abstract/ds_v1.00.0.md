本课程设计为一个基于 LM358 运算放大器的温度检测系统

feature:
- 使用 NTC 热敏电阻作为温度传感器
- 基于 LM358 运算放大器构成差分放大电路
- 利用惠斯通电桥检测热敏电阻阻值变化
- 基于 LM393 比较器实现温度阈值比较
- 使用 LED 指示灯输出温度超限报警
- 具有两级放大电路，放大倍数可调

This course design is a temperature detection system based on LM358 operational amplifier

feature:
- Uses NTC thermistor as temperature sensor
- Differential amplifier circuit based on LM358 operational amplifier
- Wheatstone bridge for detecting resistance change of thermistor
- LM393 comparator for temperature threshold comparison
- LED indicators for temperature alarm output
- Two-stage amplifier circuit with adjustable gain
