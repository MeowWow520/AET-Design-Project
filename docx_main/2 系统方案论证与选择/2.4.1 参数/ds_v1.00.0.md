# 2.4.1 LM393 的主要特性与参数 — 数据对照表

## 表 2-11 LM393 芯片基本概况

| 参数 | 说明 |
|------|------|
| 制造商 | 国家半导体（National Semiconductor）/ 德州仪器（TI）/ 安森美（ON Semi）等多厂生产 |
| 器件类型 | 双路低功耗低失调电压比较器 |
| 内部结构 | 片内集成两个独立的精密电压比较器 |
| 输出结构 | 开集电极（Open-Collector）输出，需外接上拉电阻 |
| 封装形式 | DIP-8 / SOP-8 / TSSOP-8 等 |

## 表 2-16 LM393 适用于本设计的核心优势

| 特性 | 对本设计的价值 |
|------|----------------|
| 开集电极输出 | 输出电平由外部上拉电压决定，可直接驱动 LED 或与不同电压系统接口 |
| 宽电源电压范围（2~36V 单电源） | 可共用系统的 +12V 电源，减少电源种类 |
| 输入共模范围包含地（0V） | 适合接收放大电路输出的单端电压信号 |
| 低输入偏置电流（25nA typ.） | 对前级放大电路的输出阻抗不敏感 |
| 可直接驱动 LED（灌电流 ≥ 6mA） | 输出端可直接连接 LED 与限流电阻至电源，无需额外驱动电路 |
| 低功耗（0.4mA typ. 静态电流） | 适合长期连续工作，系统整体功耗低 |
| 与 LM358 同为 DIP-8 封装 | 便于统一采购和 PCB 布局设计 |
| 低成本、市场供应充足 | 单颗价格不足 1 元，适合教学与低成本产品 |
