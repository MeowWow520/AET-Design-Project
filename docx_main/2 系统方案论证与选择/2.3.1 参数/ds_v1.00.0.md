# 2.3.1 LM358 的主要特性与参数 — 数据对照表

## 表 2-5 LM358 芯片基本概况

| 参数 | 说明 |
|------|------|
| 制造商 | 国家半导体（National Semiconductor）/ 德州仪器（TI）等多厂生产 |
| 器件类型 | 双路通用运算放大器 |
| 内部结构 | 片内集成两个独立的高增益、频率补偿运算放大器 |
| 封装形式 | DIP-8 / SOP-8 / MSOP-8 等 |

## 表 2-10 LM358 适用于本设计的核心优势

| 特性 | 对本设计的价值 |
|------|----------------|
| 单电源供电（3~32V） | 可用 +12V 单电源为运放供电，简化电源设计 |
| 双运放集成于一片 | 一片 LM358 即可完成两级差分放大，减少器件数量与 PCB 面积 |
| 输入共模范围包含地（0V） | 适合处理惠斯通电桥输出的共模电压信号 |
| 低输入偏置电流（45nA typ.） | 对电桥分压网络的高阻抗测量点影响极小 |
| 输出可摆动至地（0V） | 输出信号可在 0V 附近线性工作，适合后级比较器输入 |
| 低成本、市场供应充足 | 单颗价格低于 1 元，适合批量教学场景或低成本产品 |
| 内部频率补偿 | 无需外接补偿电容，电路简洁，调试方便 |
