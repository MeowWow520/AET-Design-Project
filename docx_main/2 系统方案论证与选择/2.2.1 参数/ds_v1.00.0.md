# 2.2.1 NTC 热敏电阻的测温原理 — 参数对照表

## 表 2-1 NTC 热敏电阻基本特性参数

| 参数名称 | 说明 |
|----------|------|
| 元件类型 | 负温度系数（NTC）热敏电阻 |
| 敏感材料 | 锰（Mn）、钴（Co）、镍（Ni）等过渡金属氧化物烧结陶瓷 |
| 温度系数 | 负温度系数，温度升高 → 阻值下降 |
| 阻值-温度关系 | 非线性指数关系，近似公式：R(T) = R₂₅·exp[B·(1/T − 1/298.15)] |
| 测温范围 | −40°C ~ +125°C（不同型号有所差异） |

## 表 2-2 阻值-温度关系式中的变量说明

| 符号 | 名称 | 单位 | 说明 |
|------|------|------|------|
| R(T) | 工作温度下的阻值 | Ω | 温度 T 时对应的电阻值 |
| R₂₅ | 标称阻值 | Ω | 25°C（298.15K）时的基准电阻值 |
| B | 材料常数（B 值） | K | 表征 NTC 材料热敏特性的特征参数，B 值越大灵敏度越高 |
| T | 工作温度 | K | 绝对温度，T = t(°C) + 273.15 |
| T₂₅ | 基准温度 | K | 298.15 K（即 25°C） |

## 表 2-3 NTSD0XV103 型 NTC 热敏电阻主要参数

| 参数 | 规格 |
|------|------|
| 制造商 | Murata（村田制作所） |
| 型号 | NTSD0XV103 |
| 25°C 标称阻值 R₂₅ | 10 kΩ |
| 材料常数 B 值 | 3900 K |
| 阻值精度 | ±3% |
| 工作温度范围 | −40°C ~ +125°C |
| 封装形式 | 径向引线（Radial），柔性导线 |
| 端子表面处理 | 铜（Copper） |
| 适用场景 | 温度检测与温度补偿 |

## 表 2-4 NTSD0XV103 典型温度-阻值对照表（B = 3900 K，近似值）

| 温度 t (°C) | 绝对温度 T (K) | 阻值 R (kΩ) |
|-------------|----------------|-------------|
| 0 | 273.15 | ≈ 33.0 |
| 25 | 298.15 | 10.0 |
| 50 | 323.15 | ≈ 3.6 |
| 75 | 348.15 | ≈ 1.5 |
| 100 | 373.15 | ≈ 0.72 |

> 注：表中阻值按公式 R(T) = R₂₅·exp[B·(1/T − 1/298.15)] 计算，其中 B = 3900 K，R₂₅ = 10 kΩ。实际器件存在 ±3% 的标称容差。
